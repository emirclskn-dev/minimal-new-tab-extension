# Güvenlik Politikası

## Desteklenen sürüm

Güvenlik düzeltmeleri projenin en güncel yayımlanmış sürümüne uygulanır.

## Güvenlik açığı bildirimi

Bir güvenlik açığını herkese açık issue olarak paylaşmayın. GitHub reposundaki **Security → Report a vulnerability** alanını kullanın. Rapor; etkilenen sürümü, yeniden üretme adımlarını ve olası etkisini içermelidir.

Pexels API anahtarı yalnızca Cloudflare Worker secret'ı olarak tutulmalıdır. Anahtarın kaynak koduna, uzantı ayarlarına veya issue içeriğine eklenmesi desteklenmez.

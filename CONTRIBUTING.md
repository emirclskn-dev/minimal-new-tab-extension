# ECLABS Launch'a katkı

Katkılar issue ve pull request olarak kabul edilir. Büyük değişikliklerden önce kapsamı bir issue içinde tartışın.

## Geliştirme

1. Repoyu fork edin ve klonlayın.
2. Değişiklik için kısa isimli bir branch oluşturun.
3. Brave veya Chrome'da `chrome://extensions` sayfasından klasörü paketlenmemiş uzantı olarak yükleyin.
4. Vanilla HTML, CSS ve JavaScript yapısını koruyun; remote script, takip sistemi veya gereksiz izin eklemeyin.
5. Liste/ikon görünümü, açık/koyu tema, import/export ve çevrimdışı fallback davranışını kontrol edin.
6. Değişikliğin amacını ve doğrulama adımlarını pull request açıklamasına yazın.

API anahtarı, token, `.dev.vars`, gerçek `wrangler.toml`, kullanıcı yolu veya kişisel veri commit etmeyin. Katkılar MIT Lisansı altında yayımlanır.
